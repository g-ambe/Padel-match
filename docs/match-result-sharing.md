# イベント終了後の共有文章

通常フレンドリー・フレンドリーチーム・オフィシャルチームの詳細画面で利用する。DB、RLS、API、認証の保存処理、既存の共有リンク操作は変更しない。SQLの手動適用や環境変数の追加は不要。

## 操作

1. イベントを終了し、既存の操作で共有リンクを作成する。
2. 「文章をコピー」で全試合の文章をコピーする。文章は画面や入力欄に表示しない。
3. スマートフォンの「LINEで共有」は `https://line.me/R/share?text=` に全文を `encodeURIComponent` で渡す。送信先の選択・送信確定はLINE側で本人が行う。アプリでは送信済みと表示しない。
4. PC、長文、ポップアップの開始失敗では全文をコピーし、LINEへの貼り付けを案内する。コピーが拒否された場合も日本語で失敗を案内する。

共有URLの長さが8,000文字を超えた場合は、ブラウザや外部アプリの制限に備えてコピーへ切り替える。この値はLINEの保証する上限ではない。文章や動画URLの切り詰めはしない。クリップボードAPIが使えなければ、一時的な `copy` イベントと従来のコピー操作を試す。画面・テキストエリアへ文章を挿入しない。

## データと状態

- 表示条件は `status === "closed"`。未作成・停止・削除済み・トークン不正は無効。ハンドラーと文章生成関数の両方でも状態を確認する。
- 画面が保持する現在の状態・トークンを利用し、押下時だけ文章を生成する。追加のDB取得や書き込みは行わない。他端末で変更した状態を確認する場合は既存画面を再読み込みする。
- 通常試合は既存画面と同じRound降順・コート順で全試合を使用する。初期表示5件による制限は文章へ適用しない。
- フレンドリーチームは既存の試合順。公式は既存の相手チーム順、その中の試合順。各画面と同じ名前解決を使い、内部IDやメールアドレスは含めない。
- 選手4名が設定されていないカードは除外する。成立するカードがなければ日本語のエラーを表示する。
- スコアは保存済みの値だけを使う。通常試合は既存の入力済み判定、チーム・公式は両得点の入力を確認する。未定の0-0は未入力、明示的な引き分け0-0は0-0として出力する。既存の集計式は変更しない。
- 動画は該当試合の登録済みURLだけを出力する。動画クリックの計測処理は呼び出さない。
- 共有URL・ログインURL・登録URLは `window.location.origin` に基づく。`/login?mode=signup` は登録フォームを初期表示し、`confirmed=true` の既存案内を優先する。

## 検証

`npm test`、`npm exec -- tsc --noEmit --incremental false`、`npm run cf:build` を実行する。

リリース前の実機確認では、iOS/AndroidのLINEがインストールされた端末で短いイベントを共有し、送信先選択画面で改行・全試合・動画・3種類のURLが残ることを確認する。LINEアプリの起動や送信完了はブラウザの自動テストでは保証できない。

併せて次を確認する。

- 3画面とも開催中はボタンなし。終了後は未作成時に無効、作成後に有効、停止で無効、再発行で最新URL、再開で非表示。
- 通常・チーム・公式で対戦ペア、得点のA/B順、未入力、引き分け、動画あり／なし、試合順が画面と一致する。
- 不完全なカードや削除済み試合が文章に含まれず、グループ未選択イベントでもコピーできる。
- PC・長文・起動失敗では全件コピーへ切り替わる。クリップボード拒否では成功表示しない。
- ダーク／ホワイト・スマートフォン／PCで表示を確認し、文章全文のプレビューがないことを確認する。
