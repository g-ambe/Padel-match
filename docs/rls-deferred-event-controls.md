## 確認できたことと未確認事項

app/events/[id]/page.tsxのコート数ボタン表示、openCourtDialog、saveCourtCountにはcanManageEventNameを要求する条件がある。このフラグは共有・動画の管理者向け条件から設定されており、一般メンバーのコート数変更を画面側で止める。

終了・再開については、今回のユーザー報告だけではボタンの表示制限、状態/モード、未保存スコア、保存時のRLS拒否などのどれが原因か確定していない。自動/手動/チームの区別と、使用画面・ボタン・エラーを次の調査で確認する。

セット06のDB合成テストでは一般メンバーのコート数変更・終了/再開が許可されるが、実画面まで同じ条件で確認できたとは扱わない。

一般メンバーの開催名変更は、現在の画面のcanManageEventNameと本番events_operation_private.guard_member_fieldsの両方で制限されている。後日の対応ではUIだけを変更して完了とせず、SQL・切り戻しSQLとDB/画面の検証をセットで用意する。公開/共有設定や開催削除まで一般メンバーへ開放する承認は得ていない。
