# 保留：共有ページの参加メンバー一覧表示

セット07の実操作確認時、ユーザーから「共有で参加メンバーも表示しときたい」と要望。今回は課題登録のみ。アプリ・本番RLSの追加変更は行っていない。

## 希望する動作

終了済みイベントの共有ページで、開催名・組み合わせ・試合結果に加え、参加メンバー一覧を表示する。試合に出場していない参加者も含む一覧を想定し、実装時にゲスト・休憩中・未出場者の扱いと表示項目を確定する。

## 実装時の確認

- 既存の参加者取得と匿名SELECT許可列で表示できるか調査し、必要な表示名だけを使用する。
- メール、内部メモ、本人連携情報などを公開しない。プロフィール全体の公開権限を広げない。
- 未ログイン・ログイン済み双方で同じ共有範囲を表示する。
- 不正トークン・共有停止・開催再開・削除時の閲覧制限を維持する。
- RLS変更が必要な場合はSQL・切り戻しSQLを用意し、本番適用前に明示承認を得る。

既存33操作には追加計上しない別のWeb改善課題。公式戦とフレンドリーマッチの共有画面は異なるため、実装時に対象画面を確定する。
