# TASK-08-03：一般メンバーの通常共有権限（2026-11-24確定）

- [Issue #264](https://github.com/g-ambe/Padel-match/issues/264#issuecomment-7127045869)、親 #215。H63完了後の限定変更。
- 通常フレンドリー（auto/manual）の終了済み・未削除イベントについて、有効グループの現役一般メンバーも共有開始・停止・URL再発行・コピー可能。イベント終了/再開は従来通り。
- 個人イベント作成者・管理者の既存権限、イベント削除・動画管理・グループ管理、チーム/公式共有の権限は変更しない。未所属・退会者・匿名は更新不可。非公開名簿と公開未同意表示名は既存のトークンRPCと認可で保護する。
- DBは既存 events_operation_private.guard_member_fields() のみ置換。一般メンバーの追加例外は共有関連3列（と既存updated_at）に限る。現在の所属判定は get_my_club_memberships() と有効グループ。閉じていないイベント、削除、他の項目と同時変更、不正なトークン状態は例外対象外。既存RLS/ACL・トリガー・テーブル・データは変更しない。
- 画面は既存canManageShareの通常メンバー判定を追加、共有更新0件の成功表示を防止。使い方説明を同期。
- apply.sqlは現行定義・RLS・トリガーを照合し単一トランザクションで適用。rollback.sqlは新定義一致時のみ旧関数へ戻す（既に発行したURLや保存済みデータを書き換えない）。本番では先にDB、続けてmain配信。異常時は後続停止。新規バックアップはユーザー判断で省略。
- 限定検証：一般メンバーの開始/停止/再発行、通常運営維持、他グループ・退会・匿名・無効グループ・開催中・削除済み・チーム・混在更新の拒否、管理者経路、既存共有RPCの回帰、TypeScript/OpenNext互換性。検証と本番反映結果はIssueに記録する。
