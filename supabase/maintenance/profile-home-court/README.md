# マイページVer.4 / 0050 ホームコート

参照：`codex/profile-r2-instagram` の `docs/mockups/mypage-ui-v4-2026-11-17.html`（参照時コミット2ea57fe）。モックのデモ用保存方式は採用せず、既存React/Next.js・0048/0049の本人用機能を維持する。

## UI

- レベル/活動エリア/利き手/得意サイドはラベル付き2列。DBのpreferred_positionは変更しない。
- 戦績は従来の勝率/試合数/勝利数の3列、詳細は既存の平均得点/平均失点等をAppDialogへ移動。敗北や引分数を新しく推算しない。補助リンクは控えめな文字色と右矢印のみ。
- 所属グループは既存の直近90日利用順の上位3件。4件以上は同じ順序の全件POP。「グループを探す」「グループ新規作成」「グループ管理へ」は3列・同じ配色。画像/人数の取得は追加しない。
- 活動エリアは広域か47都道府県から1つ選択。自由入力の既存値は「登録済み」の選択肢として保持し、他項目だけの保存でトリム/変換しない。
- 写真は従来どおり、この写真画面の保存で確定する。「この位置を保存」「この写真を保存」とし、プロフィール全体の保存とは別であることを明示。別写真の選択と削除は主操作の下へ分離。削除は保存時の確認後に実行する。

## 保存方式

既存の `padel_facilities` は0015/0017で登録・公開SELECTが実装され、グループ画面でも利用している。編集POPを開いたときだけ施設名候補を読み、未掲載の施設は自由入力可能とする。施設IDの新たな紐付け/施設マスター編集は行わず、コート名のスナップショットを保存する。マスターの改名で個人の登録名を勝手に変更しない。

0050は既存の本人専用 `player_profile_private` に `home_court_name`（任意、最大80文字、制御文字不可）と独立した `home_court_version` を追加。既存レコードは未設定/版0。R2画像キー・画像版・位置設定・Instagram・公開プロフィールを変更しない。

`PATCH /api/profile-media/:id/home-court` は既存の認証・正規プロフィール確認・試行制限を再利用し、`save_my_home_court` で版をCAS照合する。RLSは変更せず、直接UPDATE/匿名/別人/複数有効連携を拒否。未確定応答は再取得した値/版で確認し、他端末の変更へ自動追従して上書きしない。所有者変更時はトリガーで登録名をクリアする。

公開プロフィール・ホームコート・Instagramは既存の別保存経路を維持する。先に確定した項目があり後続だけ失敗した場合は一部保存済みと表示し、編集内容を保持する。確定したホームコートの期待版を更新し、再試行で二重更新/上書きしない。

## 本番適用と復旧

1. main/PR head/0050 SHA-256を固定。既存 `cloud-db-backup.yml` をmainで実行し、最新の暗号化実ファイルを非公開Draft Releaseへ保管。別ジョブで復元・全旧データ/カタログ/権限/参照を照合する。
2. `01_preflight.sql` で0049適用済み、0050未適用、本人専用保護、施設名SELECTを読み取り確認。
3. `profile-home-court-release.yml` の `211隔離検証` または条件付き承認済みの `211本番0050適用` ラベルで最新バックアップを実ファイルから隔離復元し、0050/`02_verify.sql`/`03_smoke.sql`/旧データ不変/取り消し・再適用を確認する。
4. 本番適用ラベルでは全確認が通った場合だけ、固定headの0050と履歴を1トランザクションで適用。既存データ/カタログがバックアップ時から変わっていれば適用前に停止する。比較除外は新しいホームコート2項目と0050履歴1行のみ。
5. 事後にデータ・RLS・GRANT・保存/権限拒否を検証。専用一時プロフィールの試験は全書込みをROLLBACK。既存の本人情報や画像をテストに使わない。
6. 条件を満たしたら通常のSquash mergeと既存Cloudflare自動デプロイ。Worker/R2/秘密値/本番URLの変更はない。

適用失敗は全体ROLLBACK。応答喪失時は再適用せず状態を読み取り確認する。適用後の不具合でDBを自動復元しない。0049アプリと互換なので、必要なら直前アプリへ通常のレビュー手順で戻し、ホームコートの保存値は保全できる。`isolated_rollback` は隔離DBだけの検証用で、本番で実行すると登録名を失うため自動実行しない。
